# Цифровий Шерлок

Програми з профорієнтаційного заняття «Цифровий Шерлок» DIIT Open Labs. Заняття проводить кафедра комп'ютерних інформаційних технологій ННІ «Дніпровський інститут інфраструктури і транспорту» Українського державного університету науки і технологій.

На занятті ми перевіряли сайт університету з відкритих джерел. Шукали документи через Google, дивились державні реєстри, відкривали старі копії сайту в архіві інтернету, читали заголовки сервера і метадані файлів. Спочатку кожен крок робили руками, а потім те саме робила програма. Ці програми лежать тут.

Головна програма `sherlock` отримує адресу сайту і за кілька секунд складає його картку. З якого року сайт є в архіві інтернету, як він називався на найстарішій копії і як називається зараз, скільки разів змінювалась головна сторінка, на якому сервері сайт працює і чи є захищене з'єднання.

Усе зроблено у двох варіантах. Папка `csharp` містить версію на C#, її я показував на занятті. Папка `python` робить те саме на Python, якщо вам ближча ця мова.

## Що в папках

| Файл | Що робить |
|---|---|
| `sherlock` | картка сайту з усіх кроків разом |
| `step3_archive` | скільки разів за кожен рік змінювалась головна сторінка сайту |
| `step4_headers` | що сервер повідомляє про себе в заголовках |
| `step5_pdfmeta` | у якій програмі і коли створено документ PDF |
| `step6_photo` | яка камера зробила фото, коли і де |

## Як запустити версію на C#

Потрібен .NET 10 SDK. На Windows його можна поставити однією командою в терміналі.

```
winget install Microsoft.DotNet.SDK.10
```

Або завантажити з dotnet.microsoft.com. Після встановлення відкрийте термінал у папці `csharp` і запустіть програму, вказавши адресу сайту після двох дефісів.

```
cd csharp
dotnet run sherlock.cs -- ust.edu.ua
dotnet run step3_archive.cs -- diit.edu.ua
dotnet run step4_headers.cs -- ust.edu.ua
```

Кожна програма займає один файл, окремий проєкт створювати не треба. Перший запуск триває довше, бо .NET збирає програму і завантажує бібліотеки, на це може піти хвилина. Наступні запуски швидкі.

Програми для метаданих беруть бібліотеки з NuGet самі. Для перевірки фото покладіть будь-який знімок у папку `data` або вкажіть шлях до нього.

```
dotnet run step6_photo.cs -- data/DSCN0025.jpg
dotnet run step5_pdfmeta.cs -- шлях/до/документа.pdf
```

## Як запустити версію на Python

Потрібен Python 3.10 або новіший і кілька бібліотек.

```
pip install requests pypdf Pillow
cd python
python sherlock.py ust.edu.ua
python step6_photo.py data/DSCN0025.jpg
```

## Робота без інтернету

Програми `sherlock` і `step3_archive` вміють зберігати результат і показувати його пізніше. Ключ `--save` зберігає відповідь у папку `data`, ключ `--offline` показує збережене.

```
dotnet run sherlock.cs -- ust.edu.ua --save
dotnet run sherlock.cs -- ust.edu.ua --offline
```

## Про межі

Програми лише читають те, що власники сайтів, архів інтернету і державні реєстри самі опублікували. Вони не входять в акаунти, не підбирають паролі і не збирають відомостей про людей. Якщо сайт не пускає автоматичні запити, програма це повідомляє і далі не йде. Архів інтернету обмежує кількість запитів, тому не запускайте програми в циклі по сотні сайтів без пауз.
